# Growth playbook — Reddit, X and repurposing

The studio makes the assets. This page is the plan for using them: which community, what
cadence, what to write, and what will get the domain banned.

!!! warning "Two rules decide whether this works"
    1. **No bots, no auto-posting.** Everything here is a human pressing send.
    2. **Lead with the number, not the site.** A post that would still be useful with the
       link removed is the only kind that survives contact with moderators.

## Positioning

Every basketball site already has points, rebounds and shooting splits. The moat is the
metrics nobody else publishes:

| Metric | What it answers |
| --- | --- |
| **Consistency score** | How reliable is this player, game to game? |
| **Home-court advantage** | How much does this club's crowd actually buy it? |
| **Fantasy ceiling / floor** | The realistic best and worst night, not the average. |
| **Assist-to-turnover, usage, PER** | Context for the numbers above. |

One proprietary metric per post. If a post reads like a box score, it is competing with
everybody; if it reads like "the quiet reason X keeps winning", it is not.

Wednesday and Friday.

## X playbook

**Profile:** `catchandstats.com` as the link, bio that says what the data is
("EuroLeague numbers you don't get in the box score. Free."), pinned post = a round recap
card with one number and the metric guide link.

### Post formats that work

| Format | Copy pattern | Example |
| --- | --- | --- |
| **Metric drop** | Number first, explanation second, link last | `88.1 consistency score. The most repeatable player in the EuroLeague right now is not the leading scorer. Full breakdown →` |
| **Head-to-head** | Two names, one metric, invite a side | `Two point guards, same minutes. One turns it over half as often. Who starts in April?` |
| **Recap** | Five numbers, no commentary | The round-recap card with a one-line intro. |
| **Reply-bait** | A claim a real fan would argue with | `Home-court advantage in Piraeus is worth more than 19 points per 100 possessions. That is a roster-level problem for everyone else.` |

### Cadence

| Day | Post | Language |
| --- | --- | --- |
| Mon | Round recap card | EN, then a quote-post in Greek |
| Tue | Metric of the day | EN + EL |
| Wed | Head to head | EN + the two players' markets (TR/SR/LT/EL) |
| Fri | Post-round player card | EN + EL |
| Sun | Digest + link to `/metrics-guide` | EN |

**Rules for X:** one hashtag maximum (`#EuroLeague`); never more than one link; reply to
your own post with the link if the post is doing well (the algorithm prefers link-free
posts, and replies keep the thread alive); quote-post with a local-language hook instead of
reposting the same text.

## Reddit playbook

Reddit is not a broadcast channel. It is a set of communities with moderators who remove
anything that smells like marketing. The plan below assumes a **brand-new account** with no
karma, and it ramps over eight weeks.

### The ramp

| Weeks | Posts | Comments | Links allowed? |
| --- | --- | --- | --- |
| 1–2 | 0 | 4–5 per week, pure answers | Never |
| 3–4 | 1 image post (recap card, no link, watermark only) | 4–5 per week | No |
| 5–6 | 1 – 2 image posts + a "how I'd read this stat" comment | 4–5 per week | Only if a mod or the rules allow it |
| 7–8 | 1 post/week in the main sub, plus club subs | 4–5 per week | Link only when the thread asks for a source |

Maintain a **9:1 ratio**: nine genuinely useful comments before one post that mentions your
site. Keep a private note of what you commented on each week — the ratio is easy to lose.

### Where to post

| Community | Audience | What belongs there | Link policy to check |
| --- | --- | --- | --- |
| `r/Euroleague` | League-wide, the main audience | Recaps, metric explainers, fantasy threads | Usually links in comments only; read the sidebar |
| `r/FenerbahceBasketbol` | Turkish club fans | Fenerbahçe comparisons, Efes/Besiktas matchups | Club-sub rules often stricter on self-promo |
| `r/kkcrvenazvezda` | Serbian Red Star fans | Zvezda/Partizan numbers | Local-language comments go further |
| `r/ZalgirisKaunas` (or the Lithuanian basketball sub) | Žalgiris | Lithuanian-player comparisons | Small subs, be a regular first |
| `r/greece`, `r/serbia`, `r/srbija` | National audiences | Only genuinely interesting league-wide numbers | No self-promo at all |
| `r/Basketball` | General | Advanced-stat explainers (methodology, not scores) | Strict on promotion |
| `r/nba` | Huge, mostly US | Only if a EuroLeague number is genuinely cross-league interesting | Rare; treat as a bonus |

**Never post the same card to two subs.** Rewrite the angle: the Greek sub gets the Greek
derby angle, the Turkish sub gets the Fenerbahçe angle.

### Post templates

**1. Image-led recap (no link)**

> **Title:** Five numbers from this EuroLeague round that the highlights missed
>
> **Body:** nothing but the image. If the sub requires text, add:
> "Consistency score measures how repeatable a player's output is game to game — the higher,
> the less you have to guess. Roast the picks below."

**2. Metric explainer (text, best for r/Basketball and r/Euroleague)**

> **Title:** I built a consistency score for EuroLeague players — here is what it exposes
> **Body:**
> The idea: a player averaging 15 points can be doing it in 15 every night, or in 25 and 5.
> Consistency score is built from the game-to-game deviation of their efficiency, scaled to
> 0–100. Top five after six rounds:
>
> | Player | Consistency |
> | --- | --- |
> | … | … |
>
> The surprise is [name] at [score] — reputation says streaky, the numbers say the opposite.
> Happy to explain how the score is calculated if anyone is interested.

**3. Value comment in a match thread (the workhorse, no link ever)**

> [Player] shot 4/11 but had the highest consistency score on the floor tonight — the misses
> came in one bad stretch, not spread across the game. That is usually what a tired rotation
> looks like on a back-to-back.

**4. Fantasy thread contribution** (r/Euroleague posts fantasy threads; fantasy ceiling/floor
is exactly what they want)

> Ceiling/floor for [player]: 38.5 / 12.1. The floor is the number that matters for a
> captain's pick — he has not gone under 12 in six games, which is why the average looks
> unremarkable and the pick still works.

**5. When a mod removes a post**

Do not argue. Reply once: "Understood — I build the site behind the numbers, happy to keep
posting images without links." Then post images only for the next four weeks.

### Reddit rules of engagement

- Disclose affiliation in the post or comment where it is relevant: *"I build
  catchandstats.com — free EuroLeague analytics, the numbers above are from it."*
- **Never** mention `/predictions` or anything betting-adjacent. That is the fastest route
  to a domain-wide ban.
- No link in titles, ever. No tracking parameters on Reddit except when the user explicitly
  clicks through from a link you were allowed to post — the studio leaves Reddit drafts
  without a URL on purpose.
- Reply to every comment for the first four hours. A post with an active author gets more
  visibility, and replies are where you learn which metric the community actually cares about.
- Log every post in the studio (Growth studio → **5. What worked**) so week 8 can be judged
  on referral sessions, not vibes.

## Repurposing pipeline

```
Mon  card (x)      → X post  +  IG carousel cover  +  Telegram digest image
Tue  metric (x)    → X post  +  IG story (story format) + TikTok/Shorts script
Wed  comparison    → X thread (3 tweets: numbers, context, question)
Fri  player (x)    → X post  +  IG feed  +  TikTok/Shorts
Sun  recap         → Telegram/Discord digest + newsletter section
```

The TikTok/Shorts script writes itself from the card: **hook** (the number), **context**
(one line about the metric), **question** ("who do you have?"), then a still of the card as
the outro with the site name on screen. No editing software needed beyond the phone's
built-in captions.

## The review loop (Sunday, 10 minutes)

The plan only compounds if something reads the numbers back. The studio does that part; the
job is to sit through it once a week:

1. **Sync GA4** in section 6 (or `manage.py sync_google --organic` on the server). Sessions per
   source are what separate "the post travelled" from "the post landed".
2. **Log the week's posts** — platform, card type, metric, impressions, engagements, clicks.
   The card type and metric fields are what make the next two steps possible.
3. **Read section 5** top to bottom: the *vs before* column first (is the click rate rising?),
   then the by-card-type and by-metric tables.
4. **Read section 7** — every red item is a leak (a link that never produced a session, reach
   without conversion); every green one is a format worth repeating. Press **Use** on a
   suggestion to draft that card immediately.
5. **Write one line** in the experiment log: what you tried, what happened, keep or kill.

If section 7 has nothing to say, there is not enough data yet — log more posts rather than
changing the plan.

## What success looks like (not follower counts)

| Window | Signal | Realistic target |
| --- | --- | --- |
| Week 1–2 | Accounts created, first 10 posts, baseline logging | Setup done, every post logged |
| Week 3–4 | First Reddit image post survives, engagement rate per platform | 2–4% on X, response rate > 50% on Reddit |
| Week 5–6 | Referral sessions from UTM links; branded searches | 50–150 sessions/month, first repeat visitors |
| Week 7–8 | A post that gets quoted/reposted by someone else; Telegram/Discord members | 300+ sessions/month, 25+ subscribers, one repeatable format identified |

Track in GA4 (referral sessions by `utm_source`), the studio's performance report, and a
single line in the growth experiment log per week. Repeat the format that won; drop the one
that did not.

## Risk list

| Risk | Mitigation |
| --- | --- |
| Reddit shadowban or sub ban | 9:1 ratio, no links until week 5, images only, no cross-posting |
| Data noise early in the season (6 games played) | Cards carry "after N games"; implausible values show "—" |
| Burnout at three hours a week | The studio fills the calendar; skip the TikTok step first if time runs out |
| Posting the wrong thing for weeks | The Sunday review loop: the report's by-metric table and section 7 both name what to stop |
| Chasing followers instead of visits | Only clicks, click rate and GA4 sessions are on the scoreboard |
| X account posting into the void | Reply to 5 bigger accounts in the niche daily during weeks 1–4 |
| A metric gets challenged publicly | `/metrics-guide` explains every formula; link it in the reply, once |
